## Explicit limits

- No live API/authenticated verification was performed in this test batch. Fixtures do not establish production availability or real credential behavior.
- Malformed first-page JSON serializes as `error` with exit code 1 and `invalid_json`; malformed later-page JSON retains prior validated rows and serializes as `partial` with exit code 3 and `invalid_json`.
- The chunked-cap fixture exercises cumulative streaming with a small cap; it does not transmit a full 8MiB payload.
- No test asserts behavior for every possible upstream pagination metadata spelling. Known continuation signals are detected and fail closed.
- All fixture accept/read paths use finite waits/timeouts and workers are joined after completion or fixture shutdown.
